# 🚀 My Developer Learning Journey

### Documenting My Progress | Learning by Building | Growing as a Developer

Welcome to my learning journey! 👋

This project is a personal learning portfolio designed to document and showcase my progress as I develop my skills in web development.

Rather than just listing technologies on a traditional portfolio, this website provides a transparent view of what I'm currently learning, what I've completed, the projects I've built, and the skills I'm continuously improving.
